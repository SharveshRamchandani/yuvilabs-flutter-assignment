# Day 4 – Finishing the Calendar Screen

Today I spent most of my time completing the remaining sections of the Calendar screen.

I started by building the **Calorie Left** section and the progress bar that shows the remaining calories. After that, I worked on the meal cards, making them reusable so I could use the same widget for different food items by only changing the data and colors.

I also completed the **Calorie Count** bar at the bottom of the screen. A good amount of time today went into making small adjustments to the spacing, sizing, and alignment so that everything looked as close to the reference design as possible.

Along the way, I continued organizing the project by separating the UI into smaller reusable widgets instead of keeping everything in a single file. This made the code much cleaner and easier to work with whenever I needed to make changes.

## What I Learned

- Creating reusable widgets for similar UI components.
- Building layouts by combining smaller Flutter widgets.
- Fine-tuning spacing and alignment to match a design more accurately.
- Keeping the project organized by separating widgets and theme files.
