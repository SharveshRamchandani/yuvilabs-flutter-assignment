# Day 5 – Starting the Insights Screen

Today I started working on the third screen of the application by building the header section.

I created a reusable **Insights Header** widget that includes the greeting message, the notification button with a glassmorphism effect, and the floating add button. Most of the time was spent adjusting the spacing, typography, and button styling so that it closely matched the reference design.

I then connected the new header to the third tab of the application by replacing the placeholder content, allowing the screen to be accessed through the existing bottom navigation.

Along the way, I also made a few small UI improvements by updating the food card menu icon color, adjusting the progress indicator background, and restoring the original background colors after testing different styles.

## What I Learned

- Building reusable header components for different screens.
- Creating glassmorphism effects using `BackdropFilter`.
- Integrating new widgets into an existing navigation flow.
- Making small UI refinements to improve consistency across the application.
