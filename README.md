# Day 2 – Breakfast Card and UI Refinements

Today I focused on building the **Breakfast** card from the dashboard design.

I recreated the layout by adding the meal information, nutrition values, action buttons, and the dropdown. Most of the work today was spent adjusting the spacing, font sizes, colors, and alignment so that the card matched the reference design as closely as possible.

I also spent some time refining the other dashboard cards by fixing spacing and alignment issues. Small changes like padding, positioning, and sizing made the overall screen look much closer to the original mockup.

## What I Learned

- Building another reusable Flutter widget from a design.
- Improving UI accuracy by adjusting spacing and alignment.
- Working with SVG icons inside Flutter.
- Understanding how small changes in padding and sizing can make a big difference in matching a design.
